# Поиск ниш на YouTube

`niche_finder.py` ищет видео по списку запросов через официальный YouTube Data API v3 и находит темы, в которых ролики небольших каналов набирают много просмотров. Результат сохраняется в `niches_ГГГГ-ММ-ДД.xlsx`.

## 1. Как получить ключ API

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и войдите в Google-аккаунт.
2. Вверху нажмите на выбор проекта, затем **New Project**. Введите любое имя и нажмите **Create**. Убедитесь, что новый проект выбран.
3. Откройте меню **APIs & Services > Library**, найдите **YouTube Data API v3** и нажмите **Enable**.
4. Откройте **APIs & Services > Credentials**, нажмите **Create credentials > API key** и скопируйте ключ.
5. (Рекомендуется) Нажмите на созданный ключ, в разделе **API restrictions** выберите **Restrict key** и отметьте **YouTube Data API v3** (и **Cloud Translation API**, если включите его для проверки на других языках). Сохраните.

Ключ бесплатный, дневной лимит 10 000 единиц квоты.

## 2. Установка

Нужен Python 3.10 или новее.

```
pip install -r requirements.txt
```

## 3. Запуск

```
python niche_finder.py
```

При первом запуске программа создаст `config.json` из `config.example.json` и попросит вставить ключ. Вставьте ключ в поле `api_key` и запустите ещё раз. Файл `config.json` добавлен в `.gitignore`, чтобы ключ не попал в репозиторий.

Можно указать другой файл настроек: `python niche_finder.py my_config.json`. Вместо поля `api_key` можно задать переменную окружения `YOUTUBE_API_KEY`.

## Настройки config.json

| Поле | Что делает |
|---|---|
| `api_key` | Ключ YouTube Data API. |
| `queries` | Список запросов: `{"q": "текст", "lang": "en", "region": "US"}`. `lang` это код языка (ISO 639-1), `region` это код страны (ISO 3166-1, две буквы). Оба необязательны. |
| **Фильтры до поиска** | Передаются в API и экономят квоту. |
| `order` | `"viewCount"` (по просмотрам) или `"relevance"` (по релевантности). |
| `published_after_days` | Только видео за последние N дней. `null` или `0` снимает ограничение. |
| `video_duration` | `"any"`, `"medium"` (4-20 минут) или `"long"` (больше 20 минут). |
| `max_results_per_query` | Сколько видео брать по запросу. Одна страница это 50 видео и 100 единиц квоты. |
| **Фильтры после поиска** | Применяются к собранным данным. `null` отключает границу. |
| `subs_min`, `subs_max` | Диапазон подписчиков канала. |
| `views_min`, `views_max` | Диапазон просмотров видео. |
| `min_duration_minutes` | Минимальная длина видео в минутах. |
| `exclude_shorts` | Убирать Shorts. |
| `keep_hidden_subs` | Оставлять видео каналов со скрытым числом подписчиков. Они помечаются «скрыто», ratio и score для них не считаются, в таблице они внизу. |
| **Оценка** | |
| `fresh_days`, `fresh_bonus` | Видео моложе `fresh_days` дней получают множитель `fresh_bonus` к score (по умолчанию 90 и 1.5). |
| **Подсказки** | |
| `suggest` | Получать подсказки YouTube для каждого запроса и сохранять их на лист «Подсказки». Квоту API не тратит. |
| `suggest_as_queries` | Прогонять подсказки как отдельные запросы (с языком и регионом исходного запроса). |
| `suggest_max_per_query` | Сколько подсказок на запрос брать в поиск. |
| **Проверка на других языках** | См. раздел ниже. |
| `translate_check` | Включить проверку. |
| `translate_top_videos` | Сколько лучших видео (по score) проверять. |
| `translate_source_langs` | Брать видео только из запросов на этих языках (по умолчанию `["en"]`). Пустой список: из любых. |
| `translate_languages` | Языки для проверки: `{"lang": "cs", "region": "CZ"}`. |
| `translate_provider` | `"auto"`, `"google_cloud"` или `"google_free"`. |
| `serbian_script` | Для сербского искать кириллицей (`"cyrillic"`), латиницей (`"latin"`) или обоими (`"both"`, два поиска). |
| `translate_min_views` | С какого числа просмотров похожий ролик считается конкурентом. |
| `translate_similarity` | Насколько название должно совпадать с переводом, от 0 до 1 (0.5 это половина слов). |
| `translate_busy_count` | Со скольких конкурентов язык считается занятым. |
| **Прочее** | |
| `daily_quota` | Дневной лимит квоты (10 000 для обычного ключа). |
| `use_cache` | Сохранять ответы API в `cache/` и использовать их повторно в тот же день. |
| `output_dir` | Папка для отчёта. |

## Как считаются показатели

- `ratio = просмотры / подписчики` (если подписчиков 0, делим на 1).
- `views_per_day = просмотры / дни с публикации`.
- `score = log10(просмотры) * log10(ratio + 1) * коэффициент свежести`.

## Отчёт

- **Видео**: ролики, прошедшие все фильтры, по убыванию score. Если видео нашлось по нескольким запросам, оно встречается один раз, а в колонке «Запрос» перечислены все запросы. Строки с ratio больше 10 подсвечены зелёным, больше 50 ярко-зелёным.
- **Ниши**: сводка по каждому запросу, по убыванию оценки ниши.
  - «Прошли фильтры (без подписчиков)»: видео, прошедшие фильтры по просмотрам, длительности и Shorts.
  - «Из них на каналах в диапазоне подписчиков»: те из них, что прошли и фильтр `subs_min`..`subs_max`.
  - Средние и медианные просмотры, лучший ratio, число свежих видео и оценка ниши (среднее трёх лучших score) считаются по видео, прошедшим все фильтры.
- **Каналы**: уникальные каналы из листа «Видео», их лучший ролик и его просмотры.
- **Подсказки**: только при `suggest: true`.

## Проверка на других языках

После основного поиска программа берёт лучшие видео (по score) из английских запросов, переводит их названия на языки из `translate_languages` и ищет эти названия на YouTube с языком и регионом каждой страны. Если похожих роликов нет, тему на этом языке никто не занял.

Как решается, что ролик похожий: названия приводятся к нижнему регистру, диакритика убирается, слова короче 3 букв отбрасываются, остальные обрезаются до 5 букв (грубый учёт падежей). Сходство это доля слов перевода, которые есть в названии найденного ролика. Сербская кириллица перед сравнением переводится в латиницу.

Вердикт по каждой паре видео и язык:
- **свободно**: нет похожих роликов с просмотрами от `translate_min_views`;
- **мало конкурентов**: похожих роликов меньше `translate_busy_count`;
- **занято**: похожих роликов `translate_busy_count` и больше.

Результат на двух листах:
- **Языки**: строка на видео, столбец на язык, цветом отмечен вердикт (зелёный, жёлтый, красный). Сортировка по числу свободных языков.
- **Переводы**: подробно по каждой паре: перевод названия, сколько найдено, сколько похожих, самый популярный похожий ролик со ссылкой и просмотрами.

Сравнение идёт только по названиям, поэтому проверяйте результат глазами: ролик на ту же тему с другим названием программа не заметит, а «свободно» значит «нет роликов с похожим названием».

**Квота.** Каждый язык это один поиск (100 единиц) на видео, для сербского при `"both"` два. 5 видео и 7 языков (сербский обоими алфавитами) это 40 поисков, около 4 000 единиц. Если квоты не хватает, программа проверяет столько видео, сколько помещается, и пишет об этом.

**Перевод.** Квоту YouTube он не тратит.
- `"google_cloud"`: официальный Cloud Translation API с тем же ключом. В Google Cloud Console того же проекта включите **Cloud Translation API** (APIs & Services > Library) и подключите платёжный аккаунт (Billing). API платный по числу символов, но есть бесплатный месячный объём, актуальные условия на странице цен Cloud Translation. Названия видео короткие, символов уходит мало.
- `"google_free"`: бесплатный неофициальный переводчик Google без настройки. Может перестать работать или временно блокировать частые запросы.
- `"auto"` (по умолчанию): сначала официальный API, если он не включён, то бесплатный.

Если перевод не удался, основной отчёт всё равно сохраняется, а программа пишет, что включить. Переводы кэшируются вместе с остальными данными.

## Квота и кэш

- `search.list` стоит 100 единиц за страницу, `videos.list` и `channels.list` по 1 единице за 50 id.
- Перед началом программа оценивает расход и останавливается с сообщением, если квоты не хватает.
- Потраченная квота считается локально в `cache/quota.json`. Google сбрасывает квоту в полночь по тихоокеанскому времени США, а счётчик программы сбрасывается по локальной дате, поэтому он приблизительный. Точный расход виден в Google Cloud Console, раздел **APIs & Services > YouTube Data API v3 > Quotas**.
- Ответы API за день лежат в `cache/ГГГГ-ММ-ДД/`. Повторный запуск в тот же день с теми же настройками не тратит квоту. Старые папки кэша можно удалять.

## Ограничения

- У API нет признака «это Shorts». Программа считает Shorts видео до 60 секунд, а также видео до 3 минут с `#shorts` в названии, описании или тегах. Фильтр `min_duration_minutes` отсекает их надёжнее.
- API округляет число подписчиков до трёх значащих цифр.
- Трансляции и премьеры (текущие и запланированные) пропускаются.
